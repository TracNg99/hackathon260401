This is a template for saving persistent memories. Replace this content with actual project context.

## How to Use This Template

1. Copy this file and rename it (e.g., `user_role.md`)
2. Update the frontmatter (name, description, type)
3. Add your memory content
4. Link it from `MEMORY.md`

## Memory Types

- **user**: Information about team members, their roles, expertise
- **feedback**: Guidance on how to approach work (what to do/avoid)
- **project**: Context about goals, deadlines, stakeholders, initiatives
- **reference**: Pointers to external systems (Linear, Slack channels, Figma links)
